
## Audio credits

The Vocal Hero piano uses a 22-note subset of the **Salamander Grand Piano** by Alexander Holm, licensed [CC-BY-3.0](https://creativecommons.org/licenses/by/3.0/) — samples in `public/samples/piano/`.

The acoustic guitar uses a 12-note subset of the **VSCO2 Community Edition** guitar (public domain / CC0, via the [tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) collection) — samples in `public/samples/guitar/`. Drums are synthesized in-app.
