
## Audio credits

The Vocal Hero piano uses a 22-note subset of the **Salamander Grand Piano** by Alexander Holm, licensed [CC-BY-3.0](https://creativecommons.org/licenses/by/3.0/) — samples in `public/samples/piano/`.

The acoustic guitar uses a 12-note subset of the **VSCO2 Community Edition** guitar (public domain / CC0, via the [tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) collection) — samples in `public/samples/guitar/`.

The upright bass (`public/samples/bass/`), drum kit one-shots (`public/samples/drums/`), clean electric guitar (`public/samples/egtr/`), string ensemble (`public/samples/strings/`), warm pad (`public/samples/pad/`) and brass section (`public/samples/brass/`) come from the **FluidR3** soundfont by Frank Wen (MIT), as per-note MP3s via [gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) and its percussion fork. The cajon is synthesized in-app.
